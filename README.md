# The Vampire Diaries

## 🎬 Nome da série
The Vampire Diaries

## 👨‍💻 Nome do aluno
Fernanda Folgoni

## 📚 Curso/Turma
Desenvolvimento de Sistemas - Turma: 1IE

## 🎯 Objetivo do projeto
O objetivo do projeto é colocar em prática os conhecimentos
aprendidos em aula sobre HTML, desenvolvendo uma página web
simples e organizada sobre uma série escolhida pelo aluno.

## 🛠️ Tecnologias utilizadas
- HTML5
- Visual Studio Code
- GitHub

## 📌 Descrição do projeto
A página desenvolvida apresenta informações sobre a série
The Vampire Diaries, incluindo seu ano de produção, diretores,
duração, classificação, gênero, país de origem e uma breve
sinopse.

Também foi adicionada uma imagem relacionada à série e um link
para uma página com mais informações.
